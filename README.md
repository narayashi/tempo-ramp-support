# Tempo Ramp

テンポを少しずつ上げながら練習するための、iPhone向けメトロノームアプリです。

A metronome app for iPhone that gradually increases the tempo as you practice.

---

## 日本語

### 主な機能

- **段階変速** — 指定した小節数ごとにテンポが自動で上がります
- **カウントイン** — 演奏前と変速前に、これから演奏するテンポでカウントが入ります
- **一時停止とやり直し** — そのテンポの先頭から再開、前後のテンポへの移動ができます
- **練習プランの保存** — テンポ設定に名前をつけて保存できます
- **拍子** — 1小節あたり1〜16拍（変拍子にも対応）
- **タップテンポ** — 画面をタップしてテンポを入力
- **バックグラウンド再生** — 画面ロック中も鳴り続けます

### 動作環境

iOS 17.0 以降

### お問い合わせ

不具合の報告やご要望は、[Issues](https://github.com/narayashi/tempo-ramp-support/issues) からお願いします。

### プライバシーポリシー

Tempo Ramp は、利用者の個人情報を一切収集しません。

- アプリが収集・送信するデータはありません
- 外部サーバーとの通信は行いません
- 設定内容（テンポ、練習プランなど）は端末内にのみ保存されます
- 広告やアクセス解析は使用していません

アプリを削除すると、保存された設定はすべて端末から消去されます。

本ポリシーに関するお問い合わせは、上記 Issues からお願いします。

## English

### Features

- **Progressive tempo** — The tempo rises automatically every set number of bars
- **Count-in** — Counts at the tempo you're about to play, before you start and before each tempo change
- **Pause and retry** — Resume from the start of the current tempo, or step to another tempo
- **Saved practice plans** — Name and save your tempo settings
- **Time signatures** — 1 to 16 beats per bar, including odd meters
- **Tap tempo** — Tap the screen to set the tempo
- **Background playback** — Keeps playing with the screen locked

### Requirements

iOS 17.0 or later

### Support

Please report bugs or request features via [Issues](https://github.com/narayashi/tempo-ramp-support/issues).

### Privacy Policy

Tempo Ramp does not collect any personal information.

- The app collects and transmits no data
- No communication with external servers
- Settings (tempo, practice plans) are stored only on your device
- No advertising or analytics

Deleting the app removes all saved settings from your device.

For questions about this policy, please use Issues above.
